## `05` — My Engineering Philosophy

I believe good engineering is about more than writing code.

It's about understanding the problem, choosing appropriate tools,
designing maintainable systems, validating assumptions, and considering
security and reliability from the beginning.

I value curiosity over assumptions, consistency over shortcuts,
and practical learning over collecting technologies without understanding them.

Every project is an opportunity to learn, experiment, improve, and build
a stronger foundation for solving more complex problems.
